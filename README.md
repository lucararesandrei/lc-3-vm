# LURA-16
LURA-16 is a virtual machine that simulates the [LC-3](https://en.wikipedia.org/wiki/Little_Computer_3).  
The purpose of this project is to learn to code my own virtual machine in C, and even add my own stuff meanwhile. I'll be following [Justin Meiners and Ryan Pendleton's guide](https://www.jmeiners.com/lc3-vm/) on writing a virtual machine for the LC-3.
